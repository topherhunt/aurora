memory

The 8 m base field stays resident; the 2 m detail is cached on disk as 256 m tiles and only the ones near you are in memory. Three holders read the field and do not share it -- this page, for collision, and the two mesh workers -- so terrain is the per-holder cost times three. See design/31-terrain-v3.md, the elevation pyramid.

layers

Each box regenerates the island without that layer and stands the world back up where you were, so a layer can be judged by its absence. Every combination is its own cache slot, so going back is instant. The sun is held at noon.

The island boots from IndexedDB when this seed, algorithm and set of boxes has been generated before; otherwise the worker runs here first. ?seed=N picks another island, ?regen forces the worker.
