Each clip is a function of a 0..1 phase, not authored keyframes -- tools/characters/animations.mjs. The sliders here edit that function's parameters live, driving the loaded character's bones directly (no re-bake needed to preview). save writes the current parameters for the current clip into tools/characters/animations.json, which generate-character.mjs reads when it bakes every character's GLB animation tracks -- so a tuning pass here changes what the next batch run ships.
